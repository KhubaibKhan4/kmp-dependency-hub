# Changelog

## 0.3.0

- Browse the top Kotlin Multiplatform libraries from klibs.io: 50 at a time, more as you scroll.
- 22 categories (Networking, Database, DI, Navigation, Images, …) with 20 libraries per page and live counts.
- Pick any artifact of a project; projects with a curated recipe install the full setup.
- Redesigned tool window: library cards with stars, platform badges and a details pane.

## 0.2.1

- Live search uses Sonatype's Central Portal, which answers in seconds instead of timing out.
- Search results rank the official publisher first.

## 0.2.0

- Recipe versions update automatically from Maven Central, Google Maven and the Gradle Plugin Portal.
- Search every library on Maven Central and Google Maven, with platform support read from module metadata.

## 0.1.0

- First release: curated recipes, multi-select install into any module and source set, diff preview, Doctor.
